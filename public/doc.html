How to Use the API

The Overnight Drift API lets any app, script, or spreadsheet calculate hypothetical stock returns from buying at the market close (4:00 PM ET) and selling at the next trading day’s open (9:30 AM ET). No API key is needed to call these endpoints, and CORS is open for browser requests.

Base URL: https://your-domain.vercel.app Format: JSON Auth: None required CORS: All origins allowed Caching: 15m bar cache + CDN s-maxage=300
1

Pick an Endpoint

Use GET /api/overnight/:ticker for one stock, or GET / POST /api/overnight for a portfolio of multiple stocks.

2

Pass Date & Amount

Provide a past US trading day as startDate (YYYY-MM-DD), your dollar amount (default 1000), and whether to compound nightly.

3

Read the JSON Result

The API returns total nights traded, win rate, initial close, latest open, final dollar value, dollar gain/loss, and return percentage.

Common Parameters

Parameter Type Default Description
ticker / tickers string / string[] VOO,NVDA,… US stock symbol(s), e.g. NVDA or MU,MRVL,CAT (or JSON array in POST).
startDate string ~21 trading days ago Past US market trading day in YYYY-MM-DD format (cannot be a weekend or NYSE holiday).
endDate string Latest trading day Optional end date (YYYY-MM-DD). Slices the simulation so the final sell occurs on the latest trading day open <= endDate. Must be on or after the next trading day following startDate.
singleNight boolean false When true, automatically stops after the very next trading day’s open following startDate (1 overnight round, even across weekends/holidays).
amount / investmentAmount number 1000 Starting investment in USD (minimum 1). Use amount in GET and investmentAmount in POST.
compound boolean true true reinvests updated balance each night; false invests only the fixed starting principal.
allocations object (POST only) Equal split Optional per-ticker dollar map, e.g. {"MU": 500, "NVDA": 500}.
GET /api/overnight/:ticker

Calculates overnight drift returns for a single stock from startDate through endDate (or the latest available market open when endDate is omitted). Pass singleNight=true to evaluate just the next trading day’s open. 

curl -s "https://your-domain.vercel.app/api/overnight/NVDA?startDate=2026-10-05&endDate=2026-10-06&compound=true&amount=1000"
curl -s "https://your-domain.vercel.app/api/overnight/NVDA?startDate=2026-10-09&singleNight=true&amount=1000"

          GET
          /api/overnight?tickers=MU,MRVL,NVDA
        

      

      

        Quick browser-friendly endpoint to calculate an equal-split basket of multiple stocks using URL query parameters. Supports endDate and singleNight=true for custom training windows and 1-night rounds.
      

      

        
        
curl -s "https://your-domain.vercel.app/api/overnight?tickers=MU,NVDA&startDate=2026-10-05&endDate=2026-10-06&compound=true&amount=1000"

      

    


    
    

      

        

          POST
          /api/overnight
        

      

      

        Calculates a multi-stock portfolio with optional endDate, singleNight, and custom dollar allocations per ticker. (Also accepts POST /api/overnight-returns.)
      

      

        
        
curl -s -X POST "https://your-domain.vercel.app/api/overnight" \
  -H "Content-Type: application/json" \
  -d '{
    "startDate": "2026-10-05",
    "endDate": "2026-10-06",
    "singleNight": false,
    "tickers": ["MU", "MRVL", "NVDA"],
    "compound": true,
    "investmentAmount": 1000,
    "allocations": { "MU": 500, "MRVL": 300, "NVDA": 200 }
  }'

Utility Endpoints


      

        GET
        /api/top-performers
      

      
Returns the top 10 overnight drift stocks from the 1-year simulation.

      

        
        
curl -s "https://your-domain.vercel.app/api/top-performers"

      


      

        GET
        /api/optimize?amount=1000
      

      
Splits any dollar amount across the 10-stock Optimal Balanced Overnight Portfolio.

      

        
        
curl -s "https://your-domain.vercel.app/api/optimize?amount=1000"

      


      

        GET
        /api/health
      

      
Checks API uptime and shows which market data feed is active.

      

        
        
curl -s "https://your-domain.vercel.app/api/health"

      

    


    
    

      
Code Examples


      JavaScript (Browser or Node 18+)
      

        
        
const res = await fetch('https://your-domain.vercel.app/api/overnight/NVDA?startDate=2026-09-10&amount=1000');
const data = await res.json();
console.log(data.ticker, `${data.percentReturn}%`, `$${data.finalValue}`);

      


      Python (requests)
      

        
        
import requests

url = "https://your-domain.vercel.app/api/overnight"
payload = {
    "startDate": "2026-09-10",
    "tickers": ["MU", "MRVL", "NVDA"],
    "compound": True,
    "investmentAmount": 1000
}
res = requests.post(url, json=payload).json()
print("Final Value:", res["portfolioSummary"]["totalFinalValue"])
print("Return %:", res["portfolioSummary"]["overallReturnPct"])

      

    


    
    

      
Error Codes

      

        

          
            

              HTTP Status
              Meaning
              When It Happens
            

          
          
            

              400
              Bad Request
              Invalid ticker format, invalid date format, weekend, or US market holiday.
            

            

              404
              Not Found
              Ticker symbol does not exist or has no market data.
            

            

              422
              No Trading Data
              No bars on startDate, endDate is earlier than the next trading day open, or startDate is the latest day with no next-day open yet.
            

            

              429
              Rate Limit Exceeded
              Upstream data provider throttled and no cached bars exist; includes Retry-After header and retryAfterSeconds.
