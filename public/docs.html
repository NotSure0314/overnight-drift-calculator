API Quickstart

The Overnight Drift API provides programmatic access to Close-to-Open return calculations, historical night-by-night compounding, top-performer rankings, and portfolio optimization for US equities.

CORS: Enabled (Any Origin) Auth: Public / Optional API Key Base URL: https://<your-domain>/api
GET /api/overnight/:ticker

Fetches the complete overnight drift performance (win rate, return %, initial close, latest open, and final balance) for a single ticker.

Parameters: startDate (YYYY-MM-DD, optional), compound (boolean, default true), amount (number, default 1000).
curl -s "http://localhost:4321/api/overnight/NVDA?startDate=2026-01-02&compound=true&amount=1000"

POST /api/overnight

Calculates compounded overnight returns across a custom basket of stocks with optional custom per-stock allocations.

curl -s -X POST "http://localhost:4321/api/overnight" \ -H "Content-Type: application/json" \ -d '{ "startDate": "2026-01-02", "tickers": ["MU", "MRVL", "NVDA"], "compound": true, "investmentAmount": 1000, "allocations": { "MU": 500, "MRVL": 300, "NVDA": 200 } }'

GET /api/top-performers

Returns the top 10 ranked overnight drift equities and ETFs from our 1-year backtest simulation.

curl -s "http://localhost:4321/api/top-performers"
GET /api/optimize?amount=1000

Returns the exact dollar and percentage allocation for the 100,000-trial Monte Carlo Optimal Balanced Overnight Portfolio.

curl -s "http://localhost:4321/api/optimize?amount=1000"

Integration Code Snippets

JavaScript (Node / Browser fetch):

const res = await fetch('https://your-domain.vercel.app/api/overnight/NVDA?startDate=2026-01-02');
const data = await res.json();
console.log(`NVDA Overnight Return: ${data.percentReturn}% | Final: $${data.finalValue}`);

Python (requests):

import requests

url = "https://your-domain.vercel.app/api/overnight"
payload = {
    "startDate": "2026-01-02",
    "tickers": ["MU", "MRVL", "CAT", "NVDA"],
    "compound": True,
    "investmentAmount": 1000
}
res = requests.post(url, json=payload).json()
print("Portfolio Final Value: $", res["portfolioSummary"]["totalFinalValue"])
print("Overall Return: ", res["portfolioSummary"]["overallReturnPct"], "%")
